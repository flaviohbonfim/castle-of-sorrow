# Optional assets (Phase 9)

The game is fully procedural by default. Drop files here only if you want
hand-made art or music to **override** the generated ones.

## Manifest

Create `public/assets/manifest.json`:

```json
{
  "sheets": {
    "skeleton.walk": {
      "file": "skeleton-walk.png",
      "frameW": 16,
      "frameH": 32,
      "frames": 2
    },
    "bat.fly": {
      "file": "bat.png",
      "frameW": 14,
      "frameH": 8,
      "frames": 2
    },
    "fishman.walk": {
      "file": "fishman.png",
      "frameW": 14,
      "frameH": 32,
      "frames": 2
    },
    "axeKnight.walk": {
      "file": "axe-knight.png",
      "frameW": 16,
      "frameH": 32,
      "frames": 2
    },
    "ghost.idle": {
      "file": "ghost.png",
      "frameW": 14,
      "frameH": 32,
      "frames": 2
    }
  },
  "music": {
    "title": "music/title.ogg",
    "castle": "music/castle.ogg",
    "boss": "music/boss.ogg"
  }
}
```

### Sheet rules

- Horizontal strip of right-facing frames.
- Frame `i` is the rect `(i * frameW, 0, frameW, frameH)`.
- `frames` must match what the procedural builder expects (usually 2 walk/fly frames).
- Left-facing frames are generated by horizontal flip at load time.

### Music rules

- Paths are relative to `/assets/` unless they start with `/`.
- If a file fails to load, the chiptune sequencer keeps playing that track.
- Loops start after the first user keypress (browser autoplay policy).

### Supported sheet keys (current)

| Key | Used by |
| --- | --- |
| `skeleton.walk` | Skeleton enemy |
| `bat.fly` | Bat enemy |
| `fishman.walk` | Fishman enemy |
| `axeKnight.walk` | Axe Knight |
| `ghost.idle` | Pale Knight NPC |
| `demon.idle` | Caged Imp NPC |
| `shopkeeper.idle` | Hermit |

Missing keys fall back to procedural art automatically.
